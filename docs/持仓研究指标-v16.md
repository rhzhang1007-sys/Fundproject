# 持仓研究指标 v16

目的：让投资者理解已有组合的构成、风险来源、持有过程和基金之间的差异。沿用柔和界面，保留三组九入口；不新增交易执行，不改其他业务页面。演示组合与个人持仓分开。

## 取舍与结构

| 入口 | 帮助理解什么 | 核心计算 |
|---|---|---|
| 股票重叠 | 资金是否通过多只基金买到了共同股票 | 同期原始净资产权重的最小值之和、重复路径占比 |
| 持股分散 | 数量多是否等于权重均匀 | 已披露股票有效只数、前十股票组合权重 |
| 组合角色 | 名称不同的基金是否仍同步变化 | 日常相关性与组合下跌日相关性、分散比 |
| 风险来源 | 谁影响平时波动，谁影响最差的日子 | 波动贡献、最差5%日均收益及损失贡献、留一法波动变化 |
| 下跌与修复 | 最深回落与长期承压有何不同 | 最大回撤、回撤压力指数、未创新高时间、修复区间 |
| 持有体验 | 换一个历史买入日、持有更久，体验如何变化 | 63/126/252交易日滚动持有结果、10/50/90分位、按月起点表 |
| 相似基金 | 持仓接近的基金，为何涨跌表现不同 | 同指数/相似披露匹配、共同区间比较、月度上涨与下跌参与率 |
| 成本与差异 | 较低费率是否伴随不同的风险结构 | 相同费用项目、收益差年化波动、同权重历史结构对照 |
| 持仓演变 | 前列股票与集中程度是否改变 | 两期同类型披露的前列留存率、排名成员变化、前列集中度 |

经理信息折叠保留为产品背景。删除原六项加权总分：规模中等更好、持仓变化更少更好等偏好缺少验证，不能靠一组权重替投资者作价值判断。也不把“涨得慢”直接判为基金不好。

## 核心方法与边界

1. 结构相似与收益相似分别量化。持仓重叠高不直接证明同行业、风险相同或可以互换。优先同指数同形式；其次用同类型、同期已披露重叠≥10%、近252个共同日收益相关性≥0.65建立研究对照。门槛为固定样本筛选值，未宣称寻优。排除同管理人下全称相同的份额重复。
2. 组合波动使用当前固定权重与样本协方差；波动贡献为wᵢ(Σw)ᵢ/(wᵀΣw)。历史价值路径按期初权重投入、基金之间不调仓，不能将两种口径混为一条个人实际账户记录。
3. 尾部采用最差5%交易日的准确样本质量，边界日可占分数权重；单基金贡献加总必须等于组合尾部损失。保留负贡献。留一法移去一只基金，其余同比例归一，属于结构研究，不保存或执行调整。
4. 回撤压力指数为全部观察点回撤比例平方均值的平方根。较深且持续较久的回撤会抬高指标。期末未恢复的区间保留为进行中，不给虚构回本日期。
5. 滚动结果对所有完整历史起点计算，窗口相互重叠。盈利频率不是未来概率。分位采用线性插值；0收益不计盈利；未满期限不补数。
6. 涨跌参与率采用共同月份、对照基金上涨/下跌子样本内两者月收益几何均值之比。各方向至少6个月；排除未结束月份。参照基金明确显示，不冒充市场指数。比较风险、收益和替代结构时全部重算到共同连续区间。
7. 已披露有效持股描述已展开部分，不因覆盖不足50%而隐藏这个条件统计；同时给出已展开组合比例，未知部分不填0也不当现金。总回报及风险仍沿用连续序列、clean、agree、无差分填补/跳过、人民币、至少200收益日等既定门槛。
8. 披露变化不再等待两份中报。若已有一季报和三季报，则同为前列披露，各取相同K（最多10）。进入或离开前列不等于建仓或清仓；缺席的权重保留null，不推断为0，不混中报全量与季报前列。
9. 费用按双方均有的项目比较。净值已扣持续费用，不二次扣除。情景不计尚未取得的申赎、交易、折溢价等个人成本。

## 数据与运行

只读取现有v14验收数据与基金主档。build-research-view.mjs为28,405个代码生成研究索引；净值不达标时仍保留身份和持仓，不伪造历史。当前9只演示基金逐只确认至少700个有效日收益与三期持仓；热门中盘、半导体、医药、消费、军工、新能源、银行、煤炭、传媒主题用于展示不同组合角色，不是投资配置建议。

新索引写入data/v16，sourceVersion绑定v14版本。每日build-analysis-view.mjs完成后同步重建；浏览器拒绝拼接不同版本。旧的6秒分片读取上限延长到20秒，失败显示重新读取按钮。演示入口#analysis-demo，金额仅用于界面和浏览器计算，个人保存的持仓、收藏、笔记、图片不改。

## AI输出

先给整体观察，再按“发现—数字依据—对理解持仓的意义—下一步查看什么”组织。解释风险与收益的取舍，提出核对目标、持有期限、重叠来源和相似基金差异等研究动作，不给具体买卖或配置指令。所有数字预先计算；模型不代算、不编造评分，不把样本频率说成未来概率。每条必须能回到输入指标及日期。
