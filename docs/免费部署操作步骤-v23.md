## 第一步：建立免费的状态库

1. 打开 https://supabase.com/dashboard，用自己的GitHub账号登录。
2. 新建一个项目，名称可填 fundproject-state。套餐选择Free，区域保持默认，数据库密码由你自己设置并保存。
3. 项目创建完成后，进入SQL Editor，新建查询。
4. 打开本项目 deploy/supabase-state.sql，复制整个文件，粘贴到SQL Editor，点击Run。
5. 在项目的Connect或Settings中找到Project URL，记下这个网址。
6. 在API Keys中找到服务端Secret key，通常以 sb_secret_ 开头。它稍后只填入Render后台，不填到网页、GitHub代码或聊天里。

表和函数由SQL一次建好。网页访客无权直接读写这些表；后台用服务端密钥保存状态。没有模型Key或私人笔记写入数据库。

## 第二步：创建免费的后台

1. 打开 https://dashboard.render.com，用自己的GitHub账号登录。
2. 选择 New → Blueprint，连接 rhzhang1007-sys/Fundproject 仓库的main分支。
3. Render会读取仓库根目录 render.yaml，创建 fundproject-api 服务。确认服务类型是Web Service、运行方式是Docker、实例计划是Free。
4. 按提示填写三个值：

| 名称 | 填什么 |
|---|---|
| WEB_LLM_API_KEY | 你现在使用的智增增API Key；可从本机prototype/.env.local中自行复制对应值 |
| WEB_STATE_URL | 上一步Supabase的Project URL |
| WEB_STATE_KEY | 上一步Supabase的服务端Secret key |

模型名、模型地址、备用节点、网页来源和每日预算已在配置中写好。GitHub Secrets不会自动传给Render，所以模型Key需要在此处私下填写一次。

5. 创建并部署服务，等待状态变为Live。
6. 复制Render给出的实际后台网址，形如 https://你的后台名.onrender.com 。本说明中的格式不是已经创建的地址。
7. 在这个网址后面加 /api/health 打开，看到 {"status":"ok"} 表示后台启动及状态库连接已通过。

后台地址由Render自动识别，自动部署已关闭。日更数据提交不会反复重建后台镜像。后台会按需读取GitHub的新帖子及新闻索引，因此能处理网页上当天新出现的事件和帖子。

## 第三步：把后台地址填入GitHub

1. 打开 https://github.com/rhzhang1007-sys/Fundproject/settings/variables/actions 。
2. 选择 Variables → New repository variable。
3. Name填 PUBLIC_API_ORIGIN，Value填Render给出的后台网址，只保留协议和域名，例如 https://实际后台名.onrender.com ，末尾不加 /api 或路径。
4. 保存。这里填写的是公开网址，API Key继续只放Render，不放这个变量。

发布流程会把这个后台地址自动写进网页配置。访客不需要知道后台网址，也不需要各自填写Key。

## 第四步：完成网页发布和验收

前三步完成后，提供实际后台网址即可继续完成Pages发布和跨设备验收。当前网站发布开关仍保持关闭，TeamHub仍由老师添加。
