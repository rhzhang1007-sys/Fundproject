## AI

固定语言与任务提示位于 `dist/v15-prompts.mjs`，默认AI和自选AI共用。先给简短整体解读，再给带标题的明细；新闻摘要逐篇说明。原页显示进度，SPA切换页面后继续；完成后先保存到私有资料库“AI解读”，再通知界面。保存失败仍保留可复制结果并显示失败原因。关闭或刷新网页会中断本页任务，不声称后台跨刷新常驻。

每条结论及整体解读均校验来源ID和原有数字；新闻逐条整理必须覆盖所选各篇。模型不能自行计算新的收益、比例或价格。当前界面显示的指标先由确定性代码计算，再交给AI解释。

`/api/news/body?eventId=...`只接受已收录事件ID，不接受客户端URL。服务端限制来源域名、协议、跳转、大小和超时；HTML提取正文容器，PDF按页提取可读文字。正文缓存只在 `prototype/.private/news-bodies`。有正文才分析，读取失败不退回标题伪装成全文。较长正文完整分段、分批整理后合成解读，保留来源标识。

PDF依赖安装：`python3 -m pip install -r prototype/requirements-web.txt`。如使用独立Python环境，可执行 `WEB_PDF_PYTHON=/绝对路径/python3 python3 prototype/serve.py`。本机验收使用已有运行库的pypdf，无需额外API。HTML正文与界面无新增第三方依赖。静态托管需要同时运行Node服务，反向代理同源的 `/api/`；服务端配置步骤见默认AI配置文档。

本机13:53重跑用时10.950秒，取得24729条可用净值，其中23997条日期为2026-11-25，732条为11-24；场内表1715条，两个来源未见同代码数值冲突。开放式源还列出1426个没有可用净值的条目，跳过且不补0。5个源代码尚未在网站目录中匹配，不自动建立已核身份。
