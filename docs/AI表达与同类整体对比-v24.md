# AI表达与同类整体对比

2026-11-27。延续柔和界面，只调整AI表达、最近分析关闭和基金对比。

默认AI与自选AI共用一套提示词。正文按主要发现、依据、实际意义和后续关注组织。事件保留整体与逐条摘要，帖子结合正文和评论解释观点与情绪，建设性意见落到具体资料核对和指标观察。简单提取任务按用户要求直接回答。加粗与固定色重点标记均先转义，模型不能插入HTML或自选样式。研究参考说明集中到结果末尾一行小字；原来源和数字核对继续执行。

最近分析右上角新增关闭按钮。关闭记录按页面和结果身份保存；刷新后保持关闭，产生新结果后显示新卡片。资料库、收藏与笔记继续保留。

相似基金默认增加整体对比，可选全部同类型、同指数、已收录相似持仓。全部同类型按现有公开分类筛选全部份额，不使用原12候选上限；可按ETF、联接和其他形式筛选，并搜索、排序、分页。两只详比入口保留，每行可深入比较。

新增派生文件data/v24/peer-comparisons.json，只复用既有基金基础信息与已接入净值。近252交易日和近三年均使用全组统一日期，完整覆盖后计算收益、年化波动、最大回撤、回撤压力、63交易日盈利窗口占比。管理与托管费保持同项目比较，缺值保留。中位数剔除本基金；名次包含本基金，搜索与分页不改变统计范围。不同份额独立列示，分类与行业分别理解。

Pages发布前从同一检出版本生成；每日净值流水在既有采集之后更新派生文件，没有增加数据采集或模型调用。build-peer-comparison.mjs也可独立执行。数据目录和方法有独立版本与日期，网页优先读取较新完整目录，失败回到随包版本。

基本参考：[SEC基金信息标准化比较](https://www.sec.gov/files/investor/pubs/inwsmf.htm)、[Investor.gov基金份额与费用](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-61)。本轮不新增行业推断或投资评分。
